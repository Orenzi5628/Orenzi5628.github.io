# ネコ先生のお金の豆知識（ショート動画シリーズ）

毎回同じネコ先生が、お金の豆知識を1つだけ教える、縦型ショート（約24秒）のシリーズです。Google Flow（Veo 3.1）で映像を作り、ナレーションと字幕を後から重ねます。

## シリーズの決まりごと（収益化の審査で「量産型」と見なされないために）
- **主役は毎回ネコ先生**（`assets/ref_neko_sensei.jpg`）。同じキャラクターで覚えてもらう
- **1本に豆知識は1つ**。「へぇ」と思える事実を、公式の情報で確かめてから台本にする
- **毎回、場面・小道具・動きを変える**。同じ型の繰り返しにしない（台本・プロンプトは毎回書き下ろす）
- **最初の1秒で目を引く**（音・動き・驚き）。ネコ先生はしゃべらず、表情・耳・しっぽで反応する（猫の人気動画の見せ方）
- **最後は最初の場面に戻る**（ループすると何度も見られやすい）
- 動画内に文字は入れず、字幕は編集で入れる（AI 動画は日本語の文字が崩れるため。英語版も声と字幕の差し替えだけで作れる）

## 1本の組み立て（8秒 × 3クリップ ＝ 24秒）
| クリップ | 時間 | 役割 | ナレーション |
|---|---|---|---|
| 1 | 0〜8秒 | **つかみ**：最初の1秒に事件（音と動き）→ 問いかけ | 1.6秒ごろから。問いかけで終わる |
| 2 | 8〜16秒 | **答え**：豆知識の中身を見せる | 数字やルールを1つだけ |
| 3 | 16〜24秒 | **オチ**：笑える動き → 最初と同じポーズで終わる | 一言のまとめ ＋ 行動のすすめ |

## 次の話の作り方
1. 豆知識を1つ決め、公式の情報（官公庁・日本銀行など）で確かめる
2. 上の表に合わせて、3つのセリフ（各8秒に収まる長さ、30字前後）と3つの場面を考える
3. 各クリップのプロンプト ＝ `assets/common_block.txt`（共通部分）＋ その回の場面（下の型）
4. 必要な小道具の参考画像を用意する（文字・数字のないアニメ風に）
5. ナレーション：`ep01_torn_banknote/voice/` をコピーし、`lines.tsv` を書き換えて `make_voice.py` を実行（VOICEVOX を起動しておく）
6. Flow で各クリップを 2〜3 回生成して選び、編集アプリでつないで、ナレーション（0秒の位置）・字幕・最初の大見出しを入れる

### クリップのプロンプトの型（共通部分の後ろに付ける）
```
Scene: （場所。前の話と変える）
Shot: （カメラ。1本目は「tight close-up → quick pull back」など動きのあるもの）
Action: （ネコ先生の動き。1本目は最初の1秒に事件を起こす。3本目は最初と同じポーズで終わる。口は閉じたまま）
Sound: （効果音。1本目は最初にはっきりした音）
```
