# 破れたお札、半分だけでも使える？ ― Google Flow 用 台本＆プロンプト

ネコ先生（提供画像のネコのキャラクター）がひとりで解説する、縦型ショート動画（約56秒）の台本と、Google Flow（Veo）に入れるプロンプトです。

## 伝える内容（日本銀行の引換基準）

破れたり燃えたりしたお札は、日本銀行の本店・支店で新しいお札と交換してもらえます。いくらになるかは「残っている面積」で決まります。

| 残っている面積 | 交換される金額 | 1万円札の場合 |
|---|---|---|
| 3分の2 以上 | 全額 | 10,000円 |
| 5分の2 以上〜3分の2 未満 | 半額 | 5,000円 |
| 5分の2 未満 | 交換できない（価値がなくなる） | 0円 |

- **ちょうど半分**（2分の1 ＝ 50%）は「5分の2（40%）以上・3分の2（約67%）未満」なので、**半額**になる
- 表と裏の両面が残っていることが条件
- 同じお札の破片は、面積を合わせて判定してくれる（別のお札の破片を混ぜない）
- 日本銀行の本支店での引き換えは**手数料無料**。行く前に窓口へ相談しておくと安心
- 破れたままのお札は、お店で受け取ってもらえないことがある

**出典：** [日本銀行「損傷現金の引換えについて」](https://www.boj.or.jp/about/services/bn/hikikae.htm) / [日本銀行「教えて！にちぎん：傷んだお金はどこに持ち込めばいいですか？」](https://www.boj.or.jp/about/education/oshiete/money/c09.htm) / [money-lifehack.com 解説記事](https://money-lifehack.com/article/6636) / [ファイナンシャルフィールド解説記事](https://financial-field.com/living/entry-314697)

## Flow での作り方

1. Flow で新しいプロジェクトを作り、画面の向きを **9:16（縦）** にする
2. **Ingredients to Video** を選び、ネコ先生の画像（背景が無地の全身画像）を材料として追加する
3. 下の「共通ブロック」＋各クリップのプロンプトを、**つなげて1つのプロンプトとして**貼り付けて生成する
4. 各クリップを2〜4回生成し、いちばん良いものを選ぶ（顔や服が崩れたもの、セリフが違うものは作り直す）
5. 7本を順番に並べて書き出し、編集アプリで字幕・図・BGM を入れる

**コツ**
- 共通ブロックは毎回まったく同じ文で貼る（キャラクターの見た目と声がそろいやすくなる）
- セリフの読み間違いがあったら、その言葉をひらがなにして作り直す（例：「三分の二」→「さんぶんのに」）
- お札は本物そっくりにせず、**デザインを省略したアニメ風のお札**にしている（本物そっくりの紙幣の画像は生成を断られたり、問題になったりすることがあるため）。「1万円」などの金額は字幕で見せる

## 編集で入れるもの

- **字幕**：上の台本の「セリフ」をそのまま字幕にする（AIの発音が少し違っても、字幕で正しく伝わる）
- **図・テロップ**：台本の「あとで入れる字幕・図」の列を参考にする。クリップ3〜5では、お札の残りの面積を示す図（2/3・1/2・2/5）を出すと分かりやすい
- **最後のまとめ表**（クリップ7の最後の2〜3秒、または終わりに3秒足す）

  | 残りの面積 | 交換 |
  |---|---|
  | 2/3以上 | 全額 |
  | 2/5以上 | 半額 |
  | 2/5未満 | 0円 |

- **BGM**：クリップをまたいで流れるように、編集で1曲を通して入れる（各クリップでは音楽なしで生成しているため、つなぎ目で途切れない）
- **注意書き**：「※日本銀行の引換基準（20XX年X月時点）。詳しくは日本銀行のホームページへ」などを小さく入れておくと安心

## 声をそろえたいとき（代わりの方法）

Flow の声はクリップごとに少しずつ変わることがあります。気になる場合は、

1. プロンプトの `Voice:` の行を `No dialogue. Neko-sensei moves his mouth as if talking.` に変えて、声なしで生成する
2. 前回のアニメと同じ VOICEVOX（青山龍星）でセリフを読み上げ、編集で声を重ねる

とすると、全編で同じ声になります（VOICEVOX は無料。クレジット表記「VOICEVOX:青山龍星」が必要）。
