# 破れたお札、半分だけでも使える？ ― Google Flow 用 台本＆プロンプト（約32秒）

ネコ先生（提供画像のネコのキャラクター）がひとりで解説する、縦型ショート動画の台本と、Google Flow（Veo）に入れるプロンプトです。

## 動画の設定

| 項目 | 設定 |
|---|---|
| 画面 | 縦 9:16（Flow で生成前に「9:16」を選ぶ） |
| 長さ | 8秒 × 4クリップ ＝ 32秒 |
| 出演 | ネコ先生ひとり |
| 作り方 | Flow の **Ingredients to Video**（材料から動画）に、ネコ先生の画像を「材料」として入れる |
| 声 | **VOICEVOX（雀松朱司）で作った声を、編集で後から重ねる**（`voice/` フォルダに作成済み） |
| 字幕・図・BGM | 編集アプリで後から入れる（字幕は `voice/subtitles.srt` を読み込むだけ） |

### 声を後から入れる理由
Flow でキャラクターに話させると、口の動きは Flow が作った声に合わせて動きます。そこに別の声（VOICEVOX）を重ねると、**口の動きと声がずれて不自然**になります。そこで Flow では「声なし・口は閉じたまま」で生成し、ネコ先生の声は**ナレーション（語り）として**後から入れる形にしました。これなら口と声がずれる失敗が起きません。

## 伝える内容（日本銀行の引換基準）

破れたり燃えたりしたお札は、日本銀行の本店・支店で新しいお札と交換してもらえます。金額は「残っている面積」で決まります。

| 残っている面積 | 交換される金額 | 1万円札の場合 |
|---|---|---|
| 3分の2 以上 | 全額 | 10,000円 |
| 5分の2 以上〜3分の2 未満 | 半額 | 5,000円 |
| 5分の2 未満 | 交換できない（価値がなくなる） | 0円 |

- **ちょうど半分**（50%）は「5分の2（40%）以上・3分の2（約67%）未満」なので**半額**
- 表と裏の両面が残っていることが条件。同じお札の破片は面積を合わせて判定してくれる
- 日本銀行の本支店での引き換えは手数料無料

**出典：** [日本銀行「損傷現金の引換えについて」](https://www.boj.or.jp/about/services/bn/hikikae.htm) / [日本銀行「教えて！にちぎん：傷んだお金はどこに持ち込めばいいですか？」](https://www.boj.or.jp/about/education/oshiete/money/c09.htm) / [money-lifehack.com 解説記事](https://money-lifehack.com/article/6636) / [ファイナンシャルフィールド解説記事](https://financial-field.com/living/entry-314697)
（※作成時の作業環境から日本銀行のページを直接開けなかったため、検索結果に載っていた日本銀行ページの記載で確認しています。公開前に上のリンクで最新の内容を確認してください）

## 作成済みの音声・字幕（`voice/` フォルダ）

| ファイル | 中身 |
|---|---|
| `narration_32s.wav` | 4クリップ分を並べた32秒のナレーション。**動画の頭にそろえて置くだけ**で各クリップと合う |
| `clip1.wav`〜`clip4.wav` | クリップごとの音声（各8秒。声は頭から0.4秒後に始まる）。クリップ単位で調整したいとき用 |
| `subtitles.srt` | 字幕ファイル（声とタイミングが合っている）。CapCut などで読み込める |
| `samples/` | 声の聞き比べ用（同じセリフを4つの声で読んだもの） |
| `lines.tsv` / `make_voice.py` | セリフの原稿と、音声を作り直すためのスクリプト |

- 声：**VOICEVOX:雀松朱司**（わかまつ あかし）。**動画のどこかに「VOICEVOX:雀松朱司」とクレジットを入れてください**
- 利用規約：[Virvox Project「VOICEVOXの利用規約」](https://www.virvoxproject.com/voicevoxの利用規約)（公開前に一度確認してください）

### 声の選び方
VOICEVOX 公式サイトの声の説明（[VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/)のソース [VOICEVOX/voicevox_blog](https://github.com/VOICEVOX/voicevox_blog) に載っているもの）から、落ち着いた優しい先生に合う男性の声を選びました。

| 声 | 公式の説明 | ファイル |
|---|---|---|
| **雀松朱司（採用）** | 物静かで安定した声。温厚なしっかり者の青年 | `samples/1_雀松朱司.wav` |
| 剣崎雌雄 | 安心感のある落ち着いた声 | `samples/2_剣崎雌雄.wav` |
| 離途 | 包み込む息遣いな声 | `samples/3_離途.wav` |
| 青山龍星（前の声） | 重厚で低音な声 | `samples/参考_青山龍星（今の声）.wav` |

ほかの声にしたいときは、`make_voice.py` の `SPEAKER` の番号を変えて作り直します（雀松朱司 52 / 剣崎雌雄 21 / 離途 99）。声を変えたら、クレジットと利用規約もその声のものにしてください（剣崎雌雄：[利用規約](https://frontier.creatia.cc/fanclubs/413/posts/4507)、離途：[利用規約](https://litmus9.com/#/voicebank#rules)）。
- 機械っぽさを減らす調整をしています（`make_voice.py` の先頭に説明あり）：「〜かね？」の語尾のしゃくり上げをなくす／読点・句点の間を自然な長さに／文末を少しゆっくり下げて言い切る／大事な言葉を少し強調／一音ごとの長さにわずかな揺らぎ／声のEQ・軽いコンプレッサー・ごく短い部屋の響き。調整前後は `samples/比較_調整前.wav` と `samples/比較_調整後.wav` で聞き比べられます
- 「3分の2」「5分の2」は読み間違えないよう、読み上げ用の原稿ではひらがな（さんぶんのに・ごぶんのに）にしています。字幕は数字のままです
- 各セリフは 6.3〜7.4 秒で、8 秒のクリップに収まっています

## Flow での作り方

1. Flow で新しいプロジェクトを作り、画面の向きを **9:16（縦）** にする
2. **Ingredients to Video** を選び、ネコ先生の画像（背景が無地の全身画像）を材料として追加する
3. 下の「共通ブロック」＋各クリップのプロンプトを、**つなげて1つのプロンプトとして**貼り付けて生成する
4. 各クリップを2〜4回生成し、いちばん良いものを選ぶ（顔や服が崩れたもの、口が動いてしまったものは作り直す）
5. 4本を順番につないで書き出す

**コツ**
- 共通ブロックは毎回まったく同じ文で貼る（見た目がそろいやすくなる）
- お札は本物そっくりにせず、**デザインを省略したアニメ風のお札**にしている（本物そっくりの紙幣は生成を断られたり問題になったりすることがあるため）。金額は字幕・テロップで見せる

## 編集の手順（CapCut などの無料の編集アプリで）

1. Flow の4クリップを順番に並べる（合計32秒）
2. 各クリップの音（効果音）は小さめに下げる。気になる場合は消してもOK
3. `voice/narration_32s.wav` を**0秒の位置**に置く（これだけで各クリップと声が合う）
4. `voice/subtitles.srt` を字幕として読み込む
5. 台本の「画面に入れる図・テロップ」を入れる。クリップ2・3はプロンプトで画面の左側を空けてあるので、そこに面積の図（2/3・1/2）を置くと見やすい
6. 最後の2〜3秒にまとめ表を重ねる

   | 残りの面積 | 交換 |
   |---|---|
   | 2/3以上 | 全額 |
   | 2/5以上 | 半額 |
   | 2/5未満 | 0円 |

7. BGM を1曲、全体に小さく流す（声より 12dB くらい小さく）
8. 小さく「VOICEVOX:雀松朱司」「※日本銀行の引換基準。詳しくは日本銀行のホームページへ」を入れる

## 声を作り直したいとき

セリフを変えたいときは `voice/lines.tsv`（1行1クリップ。「読み上げ用の文<TAB>字幕用の文」）を書き換えて、VOICEVOX を起動してから実行します。

```sh
docker run -d -p 50021:50021 voicevox/voicevox_engine:cpu-latest
cd voice
python3 make_voice.py
```

1つのセリフが8秒に収まらないときは、エラーで知らせるようにしてあります。

## API で作る（Flow を使わず、このターミナルから）

`api/` フォルダのプログラムで、Google の動画モデル（Gemini Omni Flash。Veo 3.1 の後継）と Gemini TTS（声）を使って作ることもできます。**どちらも `--yes` を付けたときだけ API を呼びます**（付けなければ確認表示だけで、料金はかかりません）。

### 無料で作るとき（おすすめ）
API キーの無料枠では動画は作れません（2026年10月時点。最小の設定でも利用枠 0 で断られます）。ナレーション（`gemini_narration.py`）は無料枠で作れます。
動画は **Google AI Studio の画面**（無料で1日5本ほど）で、`api/AI_Studio用プロンプト.md` のプロンプトを1本ずつ貼って作り、ダウンロードした4本を `api/out/clip1_take1.mp4`〜`clip4_take1.mp4` として置いてから `python3 assemble.py` を実行します。

### 準備
- Google AI Studio で API キーを作り、Claude Code の環境設定（クラウド環境メニュー → Edit → Network secrets／環境変数）に **`GEMINI_API_KEY`** という名前で登録する（チャットには貼らない）
- **動画の生成は有料**です。無料枠のキーでは動画も画像も「利用枠 0」で断られるので、Google AI Studio でキーのプロジェクトに**課金（Billing）を設定**してください。料金は Google の料金ページで確認してください。8秒 × 4本 = 32秒分を生成します（作り直した分は追加でかかります）
- ナレーション（Gemini TTS）は無料枠のキーでも作れました（2026年10月時点）

### 手順
```sh
cd api
pip install google-genai

# 1) ナレーション（Gemini TTS）：説明文から「優しい教授」の声を作り、4本読み上げる
python3 gemini_narration.py --design --yes   # 声を作って試し聞き用 out/voice_preview.wav を保存
python3 gemini_narration.py --yes            # out/narration_32s.wav・clip1〜4.wav・subtitles.srt
python3 gemini_narration.py --clips 1 --yes  # 気になるセリフだけ作り直す（ほかはそのまま）

# 2) 動画（Gemini Omni Flash）：ネコ先生の画像（neko_sensei.jpg）を参考に、縦 9:16・8秒 × 4本
python3 veo_clips.py --yes                   # out/clip1_take1.mp4 〜 clip4_take1.mp4
python3 veo_clips.py --clips 3 --yes         # 気に入らないクリップだけ作り直し（take2 として残る）

# 3) 仕上げ：4本をつなぎ、ナレーションと字幕を入れる（API は使わない）
python3 assemble.py                          # ../torn_banknote_short.mp4（1080x1920・32秒）
python3 assemble.py --takes 1,2,1,1          # 使う take を選ぶとき
```

### しくみと注意
- **モデル**：Veo 3.1（`veo-3.1-generate-preview`）は2026年10月時点で Gemini API から外れていて、呼ぶと後継の `gemini-omni-1.1-flash` を使うよう案内されます。`veo_clips.py` はこのモデルを Interactions API で呼びます（ファイル名は前のまま）
- **ネコ先生の再現**：Flow の Ingredients と同じ「参考画像モード」で生成します。断られた場合は自動で「Gemini の画像モデルでその場面のネコ先生の縦長の最初のコマを作り、そこから動かす」方法に切り替えます（最初のコマは `out/frames/` に保存）
- **声なしで生成**：動画モデルには「話さない・口を閉じたまま」と指示し、ナレーションは後から重ねます（口と声のずれを防ぐため）
- **声**：Gemini TTS の「Voice Design」で、説明文（落ち着いた優しい40代の大学教授、穏やかで温かい標準語）から声を作ります。作った声の ID は `out/voice_id.txt` に保存されます（2026年10月に作った声の有効期限は1年後と表示されました）。既成の声を使う場合は `--voice 声の名前` を付けます
- 生成の記録は `out/veo_log.json` に残ります
- 字幕に入れる文は `../voice/lines.tsv` の右の列です
