# 破れたお札、半分だけでも使える？ ― Google Flow 用 台本＆プロンプト（約32秒）

ネコ先生（提供画像のネコのキャラクター）がひとりで解説する、縦型ショート動画の台本と、Google Flow（Veo）に入れるプロンプトです。

## 動画の設定

| 項目 | 設定 |
|---|---|
| 画面 | 縦 9:16（Flow で生成前に「9:16」を選ぶ） |
| 長さ | 8秒 × 4クリップ ＝ 32秒 |
| 出演 | ネコ先生ひとり |
| 作り方 | Flow の **Ingredients to Video**（材料から動画）に、ネコ先生の画像を「材料」として入れる |
| 声 | **VOICEVOX（青山龍星・しっとり）で作った声を、編集で後から重ねる**（`voice/` フォルダに作成済み） |
| 字幕・図・BGM | 編集アプリで後から入れる（字幕は `voice/subtitles.srt` を読み込むだけ） |

### 声を後から入れる理由
Flow でキャラクターに話させると、口の動きは Flow が作った声に合わせて動きます。そこに別の声（VOICEVOX）を重ねると、**口の動きと声がずれて不自然**になります。そこで Flow では「声なし・口は閉じたまま」で生成し、ネコ先生の声は**ナレーション（語り）として**後から入れる形にしました。これなら口と声がずれる失敗が起きません。

## 伝える内容（日本銀行の引換基準）

破れたり燃えたりしたお札は、日本銀行の本店・支店で新しいお札と交換してもらえます。金額は「残っている面積」で決まります。

| 残っている面積 | 交換される金額 | 1万円札の場合 |
|---|---|---|
| 3分の2 以上 | 全額 | 10,000円 |
| 5分の2 以上〜3分の2 未満 | 半額 | 5,000円 |
| 5分の2 未満 | 交換できない（価値がなくなる） | 0円 |

- **ちょうど半分**（50%）は「5分の2（40%）以上・3分の2（約67%）未満」なので**半額**
- 表と裏の両面が残っていることが条件。同じお札の破片は面積を合わせて判定してくれる
- 日本銀行の本支店での引き換えは手数料無料

**出典：** [日本銀行「損傷現金の引換えについて」](https://www.boj.or.jp/about/services/bn/hikikae.htm) / [日本銀行「教えて！にちぎん：傷んだお金はどこに持ち込めばいいですか？」](https://www.boj.or.jp/about/education/oshiete/money/c09.htm) / [money-lifehack.com 解説記事](https://money-lifehack.com/article/6636) / [ファイナンシャルフィールド解説記事](https://financial-field.com/living/entry-314697)
（※作成時の作業環境から日本銀行のページを直接開けなかったため、検索結果に載っていた日本銀行ページの記載で確認しています。公開前に上のリンクで最新の内容を確認してください）

## 作成済みの音声・字幕（`voice/` フォルダ）

| ファイル | 中身 |
|---|---|
| `narration_32s.wav` | 4クリップ分を並べた32秒のナレーション。**動画の頭にそろえて置くだけ**で各クリップと合う |
| `clip1.wav`〜`clip4.wav` | クリップごとの音声（各8秒。声は頭から0.4秒後に始まる）。クリップ単位で調整したいとき用 |
| `subtitles.srt` | 字幕ファイル（声とタイミングが合っている）。CapCut などで読み込める |
| `lines.tsv` / `make_voice.py` | セリフの原稿と、音声を作り直すためのスクリプト |

- 声：VOICEVOX:青山龍星（しっとり）。**動画のどこかに「VOICEVOX:青山龍星」とクレジットを入れてください**（VOICEVOX の利用規約）
- 「3分の2」「5分の2」は読み間違えないよう、読み上げ用の原稿ではひらがな（さんぶんのに・ごぶんのに）にしています。字幕は数字のままです
- 各セリフは 5.4〜6.3 秒で、8 秒のクリップに収まっています

## Flow での作り方

1. Flow で新しいプロジェクトを作り、画面の向きを **9:16（縦）** にする
2. **Ingredients to Video** を選び、ネコ先生の画像（背景が無地の全身画像）を材料として追加する
3. 下の「共通ブロック」＋各クリップのプロンプトを、**つなげて1つのプロンプトとして**貼り付けて生成する
4. 各クリップを2〜4回生成し、いちばん良いものを選ぶ（顔や服が崩れたもの、口が動いてしまったものは作り直す）
5. 4本を順番につないで書き出す

**コツ**
- 共通ブロックは毎回まったく同じ文で貼る（見た目がそろいやすくなる）
- お札は本物そっくりにせず、**デザインを省略したアニメ風のお札**にしている（本物そっくりの紙幣は生成を断られたり問題になったりすることがあるため）。金額は字幕・テロップで見せる

## 編集の手順（CapCut などの無料の編集アプリで）

1. Flow の4クリップを順番に並べる（合計32秒）
2. 各クリップの音（効果音）は小さめに下げる。気になる場合は消してもOK
3. `voice/narration_32s.wav` を**0秒の位置**に置く（これだけで各クリップと声が合う）
4. `voice/subtitles.srt` を字幕として読み込む
5. 台本の「画面に入れる図・テロップ」を入れる。クリップ2・3はプロンプトで画面の左側を空けてあるので、そこに面積の図（2/3・1/2）を置くと見やすい
6. 最後の2〜3秒にまとめ表を重ねる

   | 残りの面積 | 交換 |
   |---|---|
   | 2/3以上 | 全額 |
   | 2/5以上 | 半額 |
   | 2/5未満 | 0円 |

7. BGM を1曲、全体に小さく流す（声より 12dB くらい小さく）
8. 小さく「VOICEVOX:青山龍星」「※日本銀行の引換基準。詳しくは日本銀行のホームページへ」を入れる

## 声を作り直したいとき

セリフを変えたいときは `voice/lines.tsv`（1行1クリップ。「読み上げ用の文<TAB>字幕用の文」）を書き換えて、VOICEVOX を起動してから実行します。

```sh
docker run -d -p 50021:50021 voicevox/voicevox_engine:cpu-latest
cd voice
python3 make_voice.py
```

1つのセリフが8秒に収まらないときは、エラーで知らせるようにしてあります。
